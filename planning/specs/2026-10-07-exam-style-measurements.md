# 시험지 양식 실측 명세

작성일: 2026-10-07 · 설계: `2026-10-07-exam-style-design.md` · 표본: `exam-samples/samples.csv`

모든 길이는 **시험지 pt**(1pt = 1/72in). 그림 픽셀 ÷ `px_per_pt`.
판정 표시: ✔ 잰 값 · ≈ 추정(꼴 대조만) · — 해당 없음.
표본마다 잰 값은 `exam-samples/<type>/*.json` 의 `measured` 칸.

## 0. 잰 방법

- **선 굵기** — 선을 가로지르는 한 줄에서 «잉크 양»(1 − 밝기/255 합) ÷ px_per_pt.
  비스듬한 선은 × cos θ. 600dpi(8.3 px/pt)에서 ±0.03pt.
- **글자 크기** — 그림 속 글자 줄의 잉크 높이 ÷ 같은 꼴의 «잉크 높이/크기» 비.
  비는 같은 PDF 본문 벡터 글자로 쟀다: 고딕 한글 줄 0.882(`신명-중고딕` 9.75pt →
  8.60pt), 명조 `(가)` 0.90, 세리프 숫자 0.76(`한양신명조`), 세리프 괄호 0.857.
  ±0.3pt 쯤 흔들린다(잘라 낸 상자·안티앨리어싱).
- **글꼴** — `glyphs.py` 대조판 + 같은 크기로 키운 조각 나란히 보기 + 획 굵기 비
  (가로로 훑은 잉크 구간 중앙값 ÷ 글자 크기).
- **잉크 문턱** 128. 회색 단계는 면적 1% 넘는 밝기 값.

### 1.4 배치 (구조)

- **제목** `〈촌락 인구 변화〉` 는 그래프 **위 가운데**. 표본 그림에는 없는 경우가 대부분
  (문제 글이 대신한다).
- **단위**는 세로축 **왼쪽 위**, 눈금 숫자 열 위에 붙는다 — `(만 명)`, `(%)`, `(°C)`.
  오른쪽 축이 있으면 그 위 오른쪽 `(mm)`.
- **가로축 단위**는 마지막 눈금 숫자에 바로 붙인다 — `2020(년)`, `15(%)`, `12(월)`,
  `100(%)`. 가로축 이름이 따로 있으면 눈금 아래 가운데(`한파 일수`).
- **세로축 이름**은 회전하지 않고 **한 자씩 세로로 쌓는다**(`폭/염/일/수`).
- **범례**는 대개 그래프 **아래 테두리 상자**(한 줄 또는 2×2). 플롯 안 오른쪽 아래·
  오른쪽 위 상자도 있다(deviation-a, radar, scatter 원 크기). 상자 없는 오른쪽 범례
  한 번(deviation-b 2027_09).
- **계열 이름**은 범례 대신 선 끝 `(가)` + 짧은 유도선으로 자주 붙인다(line ×2).
- **각주**는 왼쪽 끝 `*`, 둘째는 `* *`(공백 하나 사이). 각주 줄이 길면 둘째 줄은
  들여쓴다(deviation-b).
- **연도·출처**는 각주 **아래 한 줄** — 연도 `(2023)` 왼쪽 끝, 출처 `(통계청)` 오른쪽
  끝 (absbar ×2, stacked, scatter, treemap). 연도가 없으면 출처를 마지막 각주 줄
  오른쪽 끝에 둔다(line 2025_09, deviation-a, scatter 2026_11). 출처 없이 연도만
  있으면 연도가 각주 줄 오른쪽 끝(stacked 2026_11_wgeo, radar).
- **틀**: 막대·점·산점·꺾은선 대부분 **닫힌 사각 틀**(위·오른쪽 선 있음). 열린 L자는
  line 2026_11_wgeo 한 번, econ(화살표 축).
- **눈금 숫자**는 0 을 포함해 축 바깥 왼쪽, 오른쪽 정렬. 원점의 0 하나를 두 축이
  함께 쓰는 경우가 있다(scatter, econ).

## 2. 종류별

공통과 다른 것만.

### absbar
표본: 2026_11_korgeo-q11(+-1), 2025_09_korgeo-q17(+-1), 2025_11_wgeo-q12.
- 세로축에 눈금 표시가 **없다** — 격자 점선이 축 바로 앞(또는 축 밖 1.5pt)까지 와서
  대신한다. 가로축은 **범주 경계에 안쪽(위)** 눈금 2.5pt.
- 범주 이름 `(가)` 는 막대 아래 가운데, 명조 8.5–10pt.
- 작은 그림 여러 개(2025_09): 패널 위 `(가)` 명조 9.5pt, 범주 `1위` 는 숫자 세리프 +
  고딕.
- 막대 테두리 0.36(2025_11_wgeo 0.56 — 갈림).
- 격자 점선 1.43/1.19 인 표본 하나(2025_09) — **갈림**.

### stacked
표본: 2027_09_korgeo-q14, 2026_11_wgeo-q5(+-1), 2025_06_korgeo-q17.
- 세로 100% 막대는 absbar 와 같은 눈금 규칙. 가로 띠는 **세로 점선 격자**, 마지막
  눈금 `100(%)`.
- 채움 순서 예: 진회색 63 → 중회색 153 → 빗금 → 흰색 (2027_09), 연회색 203 → 빗금 →
  흰색 → 진회색 63 (2026_11_wgeo).
- 범례 견본 2026_11_wgeo 는 11.6pt(공통 6.2의 두 배) — **갈림**. 범례 라틴 `A`·`B` 세리프.
- **원그래프**(2025_06): 도넛 — 가운데 흰 원에 `(가)` 명조 11.1pt. 조각 안에 이름(고딕
  7.5) + 값(세리프 8.0) 두 줄, 첫 조각 값만 `(%)`. 어두운 조각은 흰 테두리 글자.
  원 테두리·조각 경계 0.39.

### line
표본: 2027_09_korgeo-q8, 2026_11_wgeo-q10, 2025_09_korgeo-q20.
- 계열 선 0.81, 강조 1.2. 기호 지름 약 2.8, 외곽 0.36. 기호와 선 종류를 함께 쓴다.
- 눈금 방향 **갈림**: 2026_11_wgeo 가로축 **바깥(아래)**, 2027_09 가로·세로 **안쪽**,
  2025_09 가로축 안쪽(위).
- 2026_11_wgeo 는 열린 L자 틀 + 가로 점선 격자, 다른 둘은 닫힌 틀. 2027_09 는 격자 없음.
- 끝 이름표 `(가)` 명조 10.1–10.3pt + 짧은 유도선 0.3 쯤.
- 패널 둘이면 각 패널 위 `〈제목〉`.

### hythergraph — 표본 없음
**line 의 계열 선·기호**와 **scatter 의 틀·격자**를 따른다.

### pyramid
표본: 2026_09_wgeo-q10(+-1).
- 남 회색 203(20%), 여 흰색, 테두리 0.39. 막대 사이 틈 없음.

  가로축 눈금 안쪽(위) 2.3pt.
- `남`·`여` 고딕 7.1 은 가로축 숫자 아래 각 쪽 가운데, `(%)` 는 오른쪽 끝, `(세)` 는

### scatter

- 가로·세로 점선 격자 모두. 점 ● 지름 2.9.

## 4. 갈린 것 · 추정 · 사용자 판단

**≈(꼴 대조만):** 고딕(→ HY중고딕), 명조 한글(→ HY신명조), 라틴 세리프 `A`·`S₁`,
treemap 숫자 자간, 범례 상자 여백.

**표본 사이에서 갈린 값:**
- 격자 점선 1.56/0.96(다수) ↔ 1.43/1.19(absbar 2025_09) ↔ 1.56/1.08(line 2025_09).
- 막대 테두리 0.30–0.39 ↔ 0.56(absbar 2025_11_wgeo).
- 눈금 방향: 안쪽(line 2027_09, pyramid, category-dot) ↔ 바깥(line 2026_11, deviation-a).
- 범례 견본 6.2 ↔ 11.6(stacked 2026_11_wgeo).
- treemap 칸 경계 검은 선 ↔ 흰 틈. matrix 표 이어진 칸 ↔ 떨어진 칸.
- 표 제목 `〈 〉`(지리) ↔ `< >`(사회문화).
- 항목 이름 `(가)` 크기 8.5 ↔ 10.3pt.

**사용자 판단이 필요한 것:**
1. **숫자 글꼴.** 시험지 숫자는 본문 `한양신명조` 숫자(홀쭉한 세리프)와 같다. 그런데
   Windows 에 깔린 `HY신명조` 의 숫자는 꼴이 다르다(넓고 가늘다). 한글은 HY 계열이
   맞으므로, 숫자만 따로 고를지(`numeral` 자리 추가 — 설계 §4 의 조건 충족) 정해야 한다.
2. **고딕은 신명 중고딕이 아니다.** 그림 속 고딕은 본문 `신명-중고딕`보다 20% 가늘고
   `HY중고딕`과 맞는다. 설계 §4 의 고딕 순서(신명 중고딕 1순위)를 HY중고딕 1순위로
   바꿀지.
3. **출처·단위는 고딕.** 초기 관찰(설계 §1 표 «`(2023)`·`(통계청)` 명조»)과 다르다 —
   출처 `(통계청)`·단위 `(만 명)` 한글은 고딕, 괄호와 연도 숫자만 세리프. 설계 §1 표를
   고칠지.
4. **기본 눈금 방향.** 표본이 갈린다 — 막대류는 «세로 없음, 가로 범주 경계 안쪽»,
   꺾은선은 안쪽이 2:1. 기본값을 안쪽으로 둘지.
5. **열린 틀 선택지.** 1.7.0 은 막대·꺾은선·산점을 늘 닫힌 틀로 그린다(시험지 다수와 같다).
   꺾은선의 열린 L자(2026_11_wgeo)를 옵션으로 더할지.
