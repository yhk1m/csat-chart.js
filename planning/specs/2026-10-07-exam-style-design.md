# 시험지 양식 그대로 — 글꼴·굵기·선까지 평가원 실물에 맞춘다

작성일: 2026-10-07 · 판 2.0.0 예정

## 1. 배경

지금 그림은 수능 시험지와 «비슷하지만 같지 않다». 2027학년도 수능 한국지리
11번(누적 막대, 통사랑 `모의고사/한국지리/작업완료/2026_11_korgeo.pdf` 3쪽)과
대조하면 차이가 바로 보인다.

| 자리 | 시험지 | 1.7.0 |
|---|---|---|
| 눈금 숫자 | 신명조 계열 세리프 숫자, **보통** 굵기 | Noto Serif KR **굵게** |
| 단위 `(만 명)`·항목 `(가)` | 명조, 보통 | Noto Serif KR 굵게 |
| 범례 | **중고딕**(돋움 꼴), 보통 | Noto Sans KR 굵게 |
| 각주 `* …` | 중고딕 | Noto Sans KR |
| `(2023)`·`(통계청)` | **명조** | 고딕 |

### 알아낸 것 — 시험지의 생김새

- 평가원 시험지(수능·모평, Acrobat Distiller)의 본문 글꼴: `신명-중명조`(본문
  11.2pt), `신명-중고딕`(자료 상자 9.7pt), `한양신명조`(숫자·괄호),
  `한양견명조`·`신명-견명조`(문항 번호), `신명-신그래픽`·`신명-디나루`(머리글),
  `GulimChe`(쪽 번호 근처).
- 교육청 학평(한글 2018 → Hancom PDF)은 다르다 — `H2mjrE`·`Haansoft Batang`·
  `Haansoft Dotum`. **이 작업의 기준은 평가원 시험지다.**
- **그래프는 벡터가 아니라 그림이다.** 약 600dpi 회색조(DeviceGray) 그림으로
  박혀 있다(위 문항: 2358×1017 px 가 283pt 폭). 그래서 그래프 속 글꼴은 PDF
  에서 이름을 읽을 수 없고, 글자 꼴을 본문 벡터 글자와 대조해 판정한다.

## 3. 1단계 — 실측 명세서

**표본.** 통사랑 PDF 중 평가원 시험 최근 3개 학년도(2025~2027), 한국지리·
세계지리·경제·사회문화·통합사회. 17종마다 대표 문항 1~3개. 시험지에 나오지
않는 종류는 «표본 없음»으로 적고 가장 가까운 종류의 규칙을 따른다.

**재는 것.** 자리별 글꼴·굵기·크기(시험지 pt), 선 굵기(축·격자·막대 테두리·
계열), 점선 무늬, 눈금 길이·방향(안/밖), 범례(테두리 상자·견본 크기·간격),
빗금 각도·간격, 회색 단계(0~255), 출처·연도·각주의 자리와 정렬, 단위 자리.

**방법.** 그림을 꺼내 픽셀로 재고 pt 로 환산한다(그림의 배치 상자 폭 ÷ 픽셀 폭).
글꼴 판정은 같은 쪽 본문 벡터 글자와 꼴 대조. 확신이 없으면 «추정»이라 적는다.

**결과물.** `planning/specs/2026-10-07-exam-style-measurements.md` + 표본
잘라낸 그림(`planning/specs/exam-samples/`). **사용자 검토를 받고 나서 2단계.**

## 4. 2단계 — 구조

- **`src/core/canvas/examStyle.ts`** — 공통 토큰: 글꼴 자리, 굵기, 선 굵기,
  점선, 회색 단계, 빗금. 종류별로만 다른 값은 그 렌더러 안에 둔다.
- **`classicStyle`** — 1.7.x 의 값을 그대로 옮긴 토큰. `style: 'classic'` 이
  고른다. 렌더러는 토큰만 읽으므로 둘 사이에 분기문이 생기지 않는다.
- **글꼴 자리.** 지금 `FontRole = 'serif' | 'sans' | 'custom'`. 실측에서 숫자가
  본문 명조와 다른 꼴로 확인되면 `numeral` 자리를 더한다. 아니면 더하지 않는다.
- **글꼴 순서**(신명의 정확한 family 이름은 설치해 봐야 안다 — 별칭을 여럿
  넣고, 사용자가 구입한 뒤 실제 이름으로 확정한다):
  - 명조: 신명 중명조 별칭들 → `'HY신명조'`, `'HYSinMyeongJo-Medium'` →
    `'Noto Serif KR'` → `serif`
  - 고딕: 신명 중고딕 별칭들 → `'HY중고딕'`, `'HYGothic-Medium'`, 돋움 →
    `'Noto Sans KR'` → `sans-serif`
  - `fontStack` 으로 사용자가 덮어쓰는 길은 지금처럼 열어 둔다.
- 렌더러 17종의 박힌 `'bold'`·선 굵기를 토큰 참조로 바꾼다.
- `ensureFonts` 는 Noto 만 내려받는다(지금과 같음). 신명·HY 는 설치된 PC 에서만
  잡힌다.
- `src/core/` 는 1.6.0 부터 이미 «이관층 그대로»가 아니다. 이번엔 17종 전부를
  건드리므로 README 의 그 설명을 걷어낸다.

## 5. 검증

- **골든 둘.** 기존 41장은 `classic` 기준으로 그대로 둔다 — 바이트 동일해야
  한다(토큰화가 옛 모양을 깨지 않았다는 증거). 새 41장은 기본(`exam`)으로 만든다.
- **대조 시트.** 종류별 «시험지 원본 | 새 결과» 나란히 놓은 HTML. 사용자가 눈으로
  확인한 뒤 새 골든을 굳힌다.
- **겹침 비교.** 누적 막대·꺾은선·기후·피라미드 4종은 시험지 자료를 그대로 넣어
  그리고 원본 위에 겹쳐 본다.
- 기존 테스트 284건·타입 검사·빌드·`docs/lib` 산출물 갱신.
